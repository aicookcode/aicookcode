# 博客封面配色方向参考

这些是可选方向，不是固定色板。使用时根据文章主题、近期封面和用户偏好进行取舍，也可以只借用情绪和明度关系，不照搬色值。

## 1. 暖杂志 / Warm Editorial

- 气质：亲切、明亮、生活化、有内容品牌感。
- 适合：AI 工具、效率工具、内容创作、产品实践、带货和面向普通用户的应用文章。
- 色彩关系：暖米白或奶油色打底，杏橙、珊瑚、焦糖、番茄红做重点，少量深棕压住层次。
- 构图建议：纸张、卡片、产品物件和柔和阴影，避免糖果色铺满画面。

## 2. 纸张与墨色 / Paper & Ink

- 气质：克制、编辑感、安静、适合长文阅读。
- 适合：方法论、工作流、教程、复盘、建站和开发实践。
- 色彩关系：象牙白、灰黑或炭色为底，搭配砖红、赭石、芥末黄或深棕作为单一强调色。
- 构图建议：留白更大，使用线稿、版面分栏、少量实物或流程卡片，不要堆满光效。

## 3. 深色高级 / Dark Premium

- 气质：沉稳、专业、有产品发布或技术专题感。
- 适合：基础设施、部署、工程实践、数据安全和复杂系统。
- 色彩关系：墨黑、深炭灰或暖深棕打底，使用铜色、金色、酒红或暖白作为光线和重点；不默认加入霓虹青绿。
- 构图建议：用一个主体和有限的高光建立层次，保留暗部细节，避免满屏发光线条。

## 4. 柔和紫灰 / Soft Lavender

- 气质：创意、轻盈、带一点设计感。
- 适合：设计工具、生成式 AI、写作、知识整理、个人效率和体验类文章。
- 色彩关系：雾紫、灰紫、奶油白、浅桃或黄油色，使用深梅紫或炭灰作为文字和轮廓对比。
- 构图建议：适合悬浮卡片、抽象形状和轻 3D 物件，保持背景简洁。

## 5. 自然材质 / Natural Material

- 气质：真实、耐看、松弛，适合降低“纯科技产品”距离感。
- 适合：独立开发、个人项目、真实案例、生活化工具和从想法到上线的记录。
- 色彩关系：沙色、陶土、亚麻白、木色、低饱和橄榄或灰褐，必要时用一处暖色强调。
- 构图建议：加入纸张、木质、布料、桌面或自然光，但主体必须与文章主题直接相关。

## 选择方法

1. 先按文章气质选一个推荐方向；
2. 再选两个差异明显的备选方向，例如暖杂志 vs 深色高级，而不是只换一个色相；
3. 查看现有首页和文章列表封面，避免连续使用相同明度和背景色；
4. 输出时描述“色彩关系和情绪”，不要把参考色值写成不可调整的硬性约束。
