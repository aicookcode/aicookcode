这个周末，我仔细研究了 OpenAI 刚发布的 GPT-5.5，重点试用了它在 Codex 中的新能力。

GPT-5.5 最强核心提升，就是 Agentic Coding 能力的大幅跃升。

它能自主构建完整项目、添加功能、编写测试、调试、大规模重构和代码审查。只需一句模糊需求，它就能自己规划整体架构、编写代码、迭代调试，一次性搞定多文件复杂任务。

看到网上有很多开发者分享的测试视频，我心痒难耐，忍不住马上想试一试。正好转头看到小朋友在预习数学，正为一元二次函数头疼。我灵机一动，在 Codex 里输入了这样一句需求：

> 生成一个网页，展示内容教小朋友认识学习一元二次函数。要生动形象。小朋友可以自己手动调整参数，可以看到不同的图像展示

结果，短短2分钟，Codex 就交出了一份成品！页面打开后，我和小朋友都惊呆了：

小朋友直接爱不释手，玩了半天不停地调整参数，大喊“这个抛物线会动！太好玩了！”那一刻，我真正感受到：AI 已经从简单的代码补全工具，转变成为了能真正理解意图、自主完成工作的靠谱伙伴。

GPT-5.5 在 Codex 中的其他亮点除了 Agentic Coding 这个最强核心，GPT-5.5 还带来了几大实用提升：

1. Browser Use
在 Codex 内置浏览器中，打开本地开发服务器（localhost），点击元素、输入内容、截图，还能在页面上直接添加注释反馈，Codex 自动修改代码并刷新预览。前端迭代和网页游戏原型开发速度直接起飞。(目前支持 Codex 桌面 APP)

2. Computer UseCodex 现在能“看到”你的屏幕，用独立光标直接操作系统上的图形界面应用，比如 Canva、Finder、Xcode、iOS Simulator 等。支持多个智能体并行工作，不干扰你自己操作。特别适合 UI 测试、跨应用自动化和原型验证。（目前支持 Codex 桌面 APP，MacOS 优先，Windows 逐步完善中）

> 🎬 原文此处为视频演示

3. Knowledge Work（知识工作与文档处理）

处理非结构化数据能力大幅增强，能自主研究、分析数据、生成专业文档、Excel 表格和 PPT。结合 Computer Use，可以端到端完成“查找信息 → 分析建模 → 输出报告”的完整流程，适合财报分析、业务规划等场景。

> 🎬 原文此处为视频演示

4. Memory & Long-horizon Tasks + 效率优化更好记住历史上下文，支持长时间连贯工作（30-45 分钟以上项目）。同时 token 消耗更少，还新增 Fast Mode，生成速度更快。上下文窗口最高支持 400K（部分计划），让复杂长期任务变得更轻松。

官方基准也非常亮眼：

- Terminal-Bench 2.0：82.7%（目前领先） —— 测试复杂命令行工作流（规划、迭代、工具协调）的能力，目前公开模型最高分。
- SWE-Bench Pro：58.6% —— 评估解决真实 GitHub 编程问题的能力，代表实际软件工程场景。相比之前版本有小幅提升，但目前 Claude Opus 4.7 在此基准上略领先。
- Expert-SWE（20 小时级任务）：73.1% —— OpenAI 内部长周期编码评测，这些任务平均需要人类工程师约 20 小时完成，体现模型处理大型、复杂项目的实力。

先行体验官们反馈：以前需要几天调试的复杂功能，现在几小时就能基本搞定👍写在最后GPT-5.5 让 AI 编程真正进入“代理时代”——你给一个模糊想法，它就能自主规划、执行、验证、优化。无论是开发者快速验证产品原型，还是普通人做教学工具、自动化工作流，都变得前所未有的简单高效。
