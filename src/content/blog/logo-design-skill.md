开网店、做自媒体、开咖啡馆，第一步往往卡在 logo 上。

请设计师，正经做一套几千块起步；自己上手，画出来的东西连自己都看不下去；网上找模板，又担心跟别人撞脸。

现在有个新路子：**让 AI 按专业设计师的流程，给你走完从需求到成品的全套**。GitHub 上一个 9 月底才开源的项目 `logo-design-skill`，一周多就涨了 1800+ Star，干的就是这件事。

- 仓库地址：[https://github.com/kaankiziltug/logo-design-skill](https://github.com/kaankiziltug/logo-design-skill)

## 它不是“一键生成 logo”，而是“请了个 AI 设计师”

市面上的 AI logo 工具不少，但大多是“一句话出图”：你说“咖啡馆 logo”，它甩你四张图，完事。好不好全凭运气，而且经常经不起细看——缩小到手机图标就糊成一团，印成单色就没法看。

这个 Skill 的思路不一样。它是给 Claude、Codex、Gemini CLI 这些 AI Agent 装的一个**专业技能包**，让 AI 按照真实品牌设计师的工作流程干活：

```text
需求访谈 → 研究同行 → 出 8-12 个创意方向
  → 挑 3 个做成 SVG → 各种测试 → 给你看方案并给出推荐
  → 你拍板 → 出完整品牌包
```

看到区别了吗？它不是直接甩成品，而是**先出小样、让你选、再深化**——跟你去找真人设计师的流程一模一样。最关键的是，它会在“给你看方案”这一步**停下来等你拍板**，不会自作主张把全套做完。你选了方向，它才继续往下做。

## 专业在哪：那些你看不见的测试

一个 logo 能不能用，设计师心里有一套“体检表”。这个 Skill 把这套体检表写成了自动化工具，每出一版都跑一遍：

- **16px 像素测试**：缩小到浏览器标签页那么大，还认得出来吗？
- **单色测试**：只用黑白印出来，效果还成立吗？
- **镜像/眯眼测试**：图形结构够结实吗？会不会看着别扭？
- **货架测试**：跟同行的 logo 放一起，会不会泯然众人？

举个例子，项目展示的 28 个案例里，有个精酿啤酒品牌，AI 在早期方案里发现一个字母的斜线角度差了 0.8 度，自动修正了——这种细节，人眼扫一眼根本看不出来，但“看着舒服”和“看着别扭”的差别，往往就藏在这里。

## 1400+ 真实 logo 参考库：学规律，不抄袭

Skill 里还带了一个 **1400 多个真实 SVG logo 的参考库**，按类型、行业、风格、情绪分好类。AI 在动手前会先去“逛”这个库：看看咖啡馆行业一般用什么构图、金融行业避开哪些俗套（比如“别再用硬币和存钱罐了”）。

注意它的原则写得很清楚：**研究规律、避开撞脸，但绝不复制**。这也是它跟某些“借鉴”工具的本质区别。

## 怎么用：三步装上

你需要先有一个支持 Agent Skills 的 AI 工具，比如 Claude Code、Codex CLI 或 Gemini CLI。以 Claude Code 为例：

```bash
# 在 Claude Code 里执行
/plugin marketplace add kaankiziltug/logo-design-skill
/plugin install logo-design@logo-design-skill
```

装完之后，新开一个对话，直接说需求就行：

> 我要开一家社区咖啡馆，叫“街角”，风格温暖、手工感，目标客群是附近居民。要一个能在门头、杯子和外卖包装上用的 logo。

AI 会先问你几个问题（定位、风格偏好、使用场景），然后去研究同类品牌，再给你出 3 套 SVG 小样，附带它的推荐理由。你选一套，它继续出完整品牌包：配色、字体搭配、横竖版组合、社交媒体头像、甚至 favicon 和 App 图标，一次配齐。

用 Codex CLI 或 Gemini CLI 的，把 `skills/logo-design` 文件夹拷到对应的 skills 目录就行，具体路径看仓库 README，写得很清楚。

## 大实话时间

先说清楚边界，免得期望错位：

1. **它代替不了顶级设计师**。几十万的品牌全案，涉及市场调研、策略定位，那是另一个维度的事。这个 Skill 解决的是“从 0 到 1 有个专业水准的 logo”，不是“拿国际大奖”。
2. **你得会提需求**。它问你定位、风格时，别回“都行”。你给的信息越具体，它出的方案越准——“温暖手工感、社区咖啡馆”就比“好看就行”强十倍。
3. **商用前做一次查重**。AI 保证不复制，但图形巧合没法 100% 避免。正式商用前，花点时间搜一下有没有高度相似的现有商标，这是对自己负责。

话说回来，对绝大多数普通人来说，“请不起设计师”和“将就用模板”之间，终于有了第三个选项：**一个按专业流程干活、随叫随到、还不要钱的 AI 设计师**。就冲这一点，这个 1.8K Star 花得值。

## 实战：一次对话是怎么推进的

光讲流程有点抽象，还原一段真实的对话节奏，你就知道怎么用了：

**你**：我要开一家社区咖啡馆，叫“街角”，想要温暖、手工感的 logo，能用在门头、杯子和外卖袋上。

**AI**（需求访谈）：先问你几个问题——目标客群年龄段？有没有偏好的颜色？要不要图形+文字组合，还是纯图形？

**你**：回答完，等它去研究同类咖啡馆的 logo 规律。

**AI**（出小样）：给你 3 套 SVG 方案，每套附一句话推荐理由，比如“A 方案的杯型负形在缩小到 16px 时依然清晰，推荐”。

**你**：选 B，但觉得颜色太冷。

**AI**：按你的选择深化，出完整品牌包：配色、字体、横竖版、杯贴 mockup、社交媒体头像。

整个过程你做的就是：**回答问题、做选择题、提修改意见**。设计功底零要求，需要的是审美判断——而审美判断，看着图做，比凭空想象容易得多。

## logo 小白常犯的 3 个错，AI 会帮你避开

1. **元素太多**：总想在一个 logo 里放咖啡杯+豆子+蒸汽+店名，AI 会提醒你做减法，一个好记的图形胜过四个堆在一起的。
2. **只看大图**：在电脑上看着挺美，印到名片上糊了。Skill 的 16px 测试就是治这个的。
3. **风格跟风**：奶茶店都用圆体字，你也用，结果十家店长一个样。AI 研究同行规律的目的之一，就是帮你找到差异化的切口。
