## 先搞懂：Pencil、Agent、MCP 到底是什么关系

动手之前，先花一分钟搞清这三者的分工，不然装到一半容易懵：

- **Pencil**：AI 设计工具，负责把文字描述变成可视化界面，是真正的“画笔”。
- **VS Code 插件**：让 Pencil 住进你的编辑器，不用来回切换软件。
- **Agent（比如 Codex）**：你的“包工头”。你跟它聊天说需求，它去指挥 Pencil 干活。
- **MCP**：Agent 和 Pencil 之间的“对讲机协议”，让 Agent 能调用 Pencil 的能力。

串起来就是一句话：**你说话 → Agent 理解 → 通过 MCP 指挥 Pencil → 画布上直接出图**。你全程只需要在聊天框里打字，剩下的都是它们之间的事。

准备工作也很简单：一个邮箱（收验证码用，国内邮箱没问题）、装好 VS Code、有一个能用的 Agent（我用的是 Codex，其他主流 Agent 都行）。

## VS Code 安装 Pencil 具体步骤

### 1. 在VSCode左侧栏找到插件入口

![](/media/pencil-agent-vscode/img_01.png)

### 2. 搜索扩展
进入插件 Extensions，搜索 Pencil。

![](/media/pencil-agent-vscode/img_02.png)

### 3. 安装扩展
点击 install 安装，看到 Disable / Uninstall 说明安装成功。并且左侧侧边栏会出现笔的图标。如果没有生效，退出重启VS Code。

![](/media/pencil-agent-vscode/img_03.png)

![](/media/pencil-agent-vscode/img_04.png)

### 4. 首次打开 Pencil，进行注册登录
点击侧边栏笔图标，打开 Pencil，第一次进入时会出现登录注册页。

直接输入邮箱即可，国内邮箱也OK。点击Send Code按钮，然后到邮箱中查看验证码

![](/media/pencil-agent-vscode/img_05.png)

输入验证码，点击Verify

![](/media/pencil-agent-vscode/img_06.png)

按提示填写显示名、用户名、邮箱、密码，完成账户初始化。

![](/media/pencil-agent-vscode/img_07.png)

注册这一步别嫌麻烦。账号的作用是把你的作品存到云端，换电脑登录还能接着改，生成的历史版本也不会丢。整个流程就是邮箱验证码那一套，没有复杂的实名，几分钟搞定。

### 5. 确认 MCP 集成
在欢迎页可看到 MCP Integrations in Terminal，确认 CLI 集成状态。根据情况选择，或者后续使用 agent 连接也OK

![](/media/pencil-agent-vscode/img_08.png)

这一步是关键中的关键。MCP 集成相当于给 Agent 配了一部能打给 Pencil 的“电话”——没有它，Agent 再聪明也指挥不动 Pencil，只能干聊天。如果你在这里看到集成状态是正常的，后面 Agent 对接基本一次通过；如果显示异常，先按页面提示修复，别急着往下走。

**6. 在 agent 聊天区让 Codex 确认对接 Pencil MCP**我用的 Codex ，所以以 Codex 为例，大家使用的 agent 都满足。直接输入类似：我现在需要在 vscode 中使用 pencil 进行设计，帮我对接 pencil mcp

![](/media/pencil-agent-vscode/img_09.png)

这句话就是个“接头暗号”，直接复制去用就行。Agent 收到后会自己去检查 MCP 连接、注册 Pencil 的工具集，全程不用你手动配 JSON、改配置文件——这也是 Agent 模式最爽的地方，以前这种对接少说要折腾半小时看文档。

### 7. agent 确认对接完成
agent 在确认连接好以后，会给出反馈。看到类似“已对接好并可执行”的反馈即可。

![](/media/pencil-agent-vscode/img_10.png)

## 怎么描述需求，AI 画得更准

正式开画之前，先掌握这套“两步走”：**第一轮用一句话定方向，方向对了再往下加细节**。

第一轮不用想太多，像下面教程里那样，直接丢一句“帮我设计一个目前门户比较流行的登录页”就行。目的是看 AI 出来的大方向对不对——布局顺不顺眼、像不像你要的东西。方向错了，换个说法重来，成本极低。

方向对了，第二轮再加约束。好描述的公式是：**风格 + 布局 + 关键元素 + 参考对象**：

> “改成深色风格，左侧品牌介绍、右侧登录表单，支持企业微信和飞书扫码登录，整体参考 Linear 官网的简洁风”

风格（深色/浅色）、布局（左右分栏/居中卡片）、关键元素（扫码登录）、参考对象（Linear 官网）——四个里能说清三个，AI 基本不会跑偏。

记住这个顺序：**先粗后细**。一上来就写小作文，AI 可能在你没想清楚的地方自作主张；先看一版，有了具体画面再提修改，你的要求会提得更准，AI 也改得更明白。

## VS Code 使用 Pencil 具体步骤

### 1. 输入你的想法

在 agent 聊天框中输入你的想法，比如“帮我设计一个目前门户比较流行的登录页”，这时候 agent 就开始工作啦。工作过程中会有一些确认弹窗，点击 Approve 继续。

![](/media/pencil-agent-vscode/img_11.png)

看到 Approve 别慌，这是 Agent 在申请“动手权限”——它要调用 Pencil 的工具了，问你同不同意。点同意就行，相当于你点头说“去画吧”。

### 2. 输出界面

agent 会通过 MCP 调用 Pencil 工具，创建或编辑 .pen 文件，并把生成结果实时渲染到 VS Code 画布中。

下图就是我把想法丢进去后生成的界面。效果居然真不错，已经到了“我这个只会写代码的人也敢点评配色了”的程度。对设计小白来说，确实有点神奇，也有点上头。

![](/media/pencil-agent-vscode/img_12.png)

顺带一提，`.pen` 文件就是 Pencil 的“源文件”，相当于设计的源代码。Agent 每次修改都是在编辑这个文件，所以你的每一版都有迹可循，想回退、想对比都很方便，不会像某些 AI 生图工具那样，关掉就没了。

### 3. 继续迭代修改

不过还是有些小瑕疵，所以继续和 agent 沟通优化修改。如：“企业微信”和“飞书”文字需要居中。

![](/media/pencil-agent-vscode/img_13.png)

迭代时记住三个诀窍：**一次只改一个地方**（别一口气提五个修改，出问题不知道是谁的锅）；**指名道姓说位置**（“左上角 logo 太大了”比“ logo 太大了”好使）；**不满意就让它换一版**（“换个配色方案再出一版”——AI 又不会累，多要几版再选）。

### 4. 查看最终效果
经过几轮你来我往的修改，可以当测试最终稿了。

## 它适合干什么、不适合干什么

玩了几天，说说大实话，帮你建立合理预期：

**适合的场景：**
- 快速出产品原型，拿去跟人对需求
- 给开发看效果图，比口头描述“大概长这样”靠谱一万倍
- 个人项目、落地页、活动页，速度优先的场景
- 探索阶段：同一个需求出三四个风格，对比着选

**别指望的场景：**
- 像素级精修：字体微调、间距强迫症，还是得设计师上
- 复杂交互和动效：它现在强在静态页面，复杂动效别为难它
- 直接上生产：生成的是设计稿，不是生产级代码，上线前还得工程师接手

定位摆正，它就是个“把脑洞快速变成看得见的东西”的工具。在这个定位上，它确实离谱。

## 几个让效果更好的小技巧

1. **先给参考，再说需求**：“参考 Stripe 官网的风格，做个定价页”——有参照物，AI 的发挥稳定得多。
2. **先定风格，再抠细节**：第一轮先定大方向（深色还是浅色、什么布局），方向对了再调按钮圆角这种细节。
3. **善用“再来一版”**：同一需求让它出 2-3 版，你当评委挑，效果比死磕一版好得多。
4. **记住几个魔法词**：配色、字体、间距、圆角、阴影。想调哪里，直接点名，AI 都听得懂。
