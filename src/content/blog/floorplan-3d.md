装修是普通人最大的一笔“想象力支出”。

沙发放这还是放那？床头柜会不会挡住插座？餐桌买 1 米 4 的，餐厅还走得过去吗？这些问题，靠脑补十有八九要翻车；请设计师出效果图，一套下来几千块；拿纸笔画，画完自己都看不懂。

GitHub 上一个 9 月底开源的项目，把这事变得特简单：**在网页上按真实比例摆家具，一键切换成 3D 样板间，还能第一人称走进去逛**。关键是免费、开源，整个工具就是一个网页文件，打开即用。

- 仓库地址：[https://github.com/wy51ai/floorplan-3d](https://github.com/wy51ai/floorplan-3d)

## 先在 2D 平面图上摆，尺寸都是真的

打开工具，先看到的是 2D 平面图，按 1:60 或 1:100 的真实比例画，单位精确到毫米——不是示意图，是真家伙。

左边是个家具库，卧室、客厅、餐厨、卫浴、家电、书房休闲，60 多种家具家电，直接拖进来：

- 拖动摆放，贴墙自动吸附，不用来回微调
- 按 R 旋转，Shift 还能自由角度
- 想砸墙？切换到拆改模式，非承重墙可以直接拆，承重墙会单独标出来提醒你——**这点很良心，乱砸承重墙是要出大事的**
- 自带测量工具，靠近墙面自动吸附，量一下过道还剩多宽

图上摆不下的纠结，在这一步基本都能解决：沙发和茶几的距离、床两边各留多少、衣柜门打开会不会撞墙，全是真实尺寸说了算。

## 一键 3D：从平面图走进样板间

按一下 `T`，平面图直接变成 3D 场景。这才是这个工具最让人“哇”的一下地方：

- **鸟瞰、斜视、俯视**随便切，点房间列表还能直接“飞”到那个房间
- **第一人称漫游**：WASD + 鼠标，像玩游戏一样在自己未来的家里走一圈，手机上是虚拟摇杆，还能点门开关
- **日照滑块**：拖一下看看下午三点阳光能不能照进客厅，买房看采光的神器
- **夜景模式**：开灯看看晚上的氛围

更绝的是，**在 3D 里也能直接拖家具**，跟 2D 平面图实时同步。你在 3D 里把沙发往前挪一点，切回 2D，位置已经变了。两边看到的永远是同一套方案，不用来回对。

## 还能顺手把装修预算估了

摆完家具，工具还能帮你算账：

- 每个房间的面积、套内使用面积自动统计
- 给房间换地面材料：木地板、地砖、大理石、水磨石、地毯随便选，按面积加 5% 损耗**估算造价**

虽然只是估算，但至少给了个锚点。拿着这个数再去跟装修公司谈，心里有底，不至于被报个天价还觉得“好像差不多”。

方案会自动保存在浏览器里，关掉再打开还在。摆出满意的版本，可以导出 PNG 图片发给家人看，或者导出 JSON 备份。

## 怎么用：真的就一个文件

```bash
git clone https://github.com/wy51ai/floorplan-3d.git
# 然后直接用浏览器打开 index.html 就行
```

没看错，不用装 Node，不用 npm install，不用起服务。**整个应用就是一个 `index.html`**，双击打开就能用（3D 部分要联网加载 Three.js，首次打开等几秒）。

想换成自己家的户型？户型数据就写在 `index.html` 里的 `ROOMS`、`WALLS` 这些变量里，照着格式改就行。README 里写了每个字段是干嘛的，稍微懂点代码就能改；完全不懂的话，先拿默认户型玩熟了再说。

## 几个实用玩法

**玩法一：装修前排雷**
把开发商给的户型图量好填进去，沙发、床、餐桌按真实尺寸摆一遍。重点检查：过道够不够 80cm、衣柜门打开撞不撞床、餐桌拉开后还能不能走人。这三处是翻车重灾区，提前在软件里撞墙，总比装修完再撞强。

**玩法二：租房党布置小屋**
出租屋一般就十几平米，每一寸都得算计。先量房间长宽，在工具里试几种布局：床横着放还是竖着放、书桌放窗边还是门边。试好了再下单买家具，避免“买回来发现放不下”的经典悲剧。

**玩法三：对比两个户型**
同时看中两套房？把两个户型都建出来，摆上同样的家具，直观对比哪个更方正、哪个浪费面积小。比看纸面数据实在得多。

**玩法四：跟家人/伴侣对齐审美**
装修吵架，一半是因为“想象的不一样”。直接把 3D 漫游的截图发家庭群，“客厅我想这样摆”配上图，比说一万句都管用。

## 进阶：换成自己家的户型

默认户型只是示例，真想用在自己房子上，得把数据换掉。户型数据在 `index.html` 里，分几个部分：

- `ROOMS`：每个房间的多边形和名称
- `WALLS` / `WINS`：墙体和窗户的位置
- `MATS`：地面材料和单价

拿卷尺量好每个房间的长宽，按格式填进去就行。README 里每个字段都有说明，不懂代码也能照着葫芦画瓢。花半小时量房填数据，换来的是“在自己家”里做实验，这买卖划算。

## 大实话时间

1. **默认户型不是你家**。工具自带一套示例户型，真想用在自己房子上，得按上面的方法把数据换成你家的。花半小时量房+填数据，值。
2. **效果是示意级的**。家具模型做得挺精细，但别指望它渲染出照片级效果图——它的强项是“空间关系对不对”，不是“好不好看”。
3. **造价只是估算**。材料单价、人工费各地差异大，估出来的数当参考，别当报价单。

但话说回来：**一个免费、打开即用、2D 和 3D 实时同步的户型工具**，在装修这件动辄几十万的事面前，帮你避开一个坑就回本了。收藏一下，买房装修那天用得上。
