用 AI 做 PPT，最怕两件事：生成的像 AI 模板，汇报拿不出手；想局部改个标题、图表，却只能重新生成整页。

最近看到的 **dashiAI PPT Skill**，想同时解决这两个问题：**生成的 PPT 要好看，生成之后也要好改。**

它可以通过 Claude Code、Codex、Workbuddy 等本地 Agent，生成一套自带编辑控制台的网页 PPT。你可以在浏览器里直接改文字、换布局、换图表，最后再导出真正可编辑的 PPTX。项目团队和专业设计师花了两个多月打磨这套 Skill。目前项目已经获得 2.5k+ Star。

GitHub： [https://github.com/chuspeeism/dashiAI-ppt-skill](https://github.com/chuspeeism/dashiAI-ppt-skill)

![dashiAI PPT 生成效果](/media/ai-ppt-design/img_01.gif)

### 好看不是偶然

这个项目内置了 **12 套视觉主题、1020 个页面版式**。

![dashiAI PPT 内置的 12 套视觉主题](/media/ai-ppt-design/img_02.png)

轻拟态适合产品介绍，冷白调研适合行业报告，深色图谱适合高密度数据，金色指数和高能增长更适合融资路演。还有深蓝杂志、黑金实验、声波霓虹等风格。

它们不只是换了一套背景颜色。专业设计团队提前处理了字体、留白、配色、图文比例和信息层级。封面、目录、指标、趋势、对比、流程、案例和结尾，也都有对应的页面结构。

图表和分析模型也不是临时生成的装饰图，版式库里已经准备了：

- 瀑布图、雷达图、漏斗图、热力图和桑基图
- 甘特图、气泡图、矩形树图和帕累托图
- SWOT、波特五力、PEST 和商业模式画布
- 双钻模型、组织架构、产业链和生态关系图

Agent 不需要每次面对一张空白画布猜怎么排，而是根据内容，从已经设计好的版式里选择更合适的一页。

**好看的关键不只是模型能力，而是先有人把设计系统搭好了。**

### 生成完成后，可以在网页里直接改

这里容易产生一个误解：它生成的是 HTML，是不是只能预览，必须导出 PPT 后才能编辑？并不是！生成完成后，打开项目提供的本地网页，就能直接编辑 PPT。

你可以点击页面里的文字直接修改。标题变长后，相关装饰元素也会根据字数自动适配。图片和视频可以点击或拖拽替换。所有修改还会自动保存到 index.html 文件中。

每一页右侧都有独立控制台，可以继续调整：

- 增加或减少目录、卡片、表格和图片数量
- 更换页面布局和主要信息重点
- 把当前图表换成另一种图表
- 切换当前主题中的预设配色
- 选择液态形变、横滑、缩放等翻页动画
- 复制、删除、跳过或拖拽重排页面

项目一共设计了 **20 多个编辑维度、8576 个可调控件**，包括 2372 个滑杆、4276 个开关和 1825 个下拉选项。

有了这些编辑功能，标题或图表不合适时直接修改就行，不用把整页推倒重来。

### 先选风格，缺图片也不用停下来

把报告、方案或其他文档交给 Agent 后，你可以说明受众、页数和需要突出的结论。

如果没有指定视觉风格，Skill 会先展示 12 套主题预览，让你自己选择，而不是直接生成一套随机风格。

接下来，它会确认是否需要图片或视频。有现成素材可以直接交给 Agent；暂时没有也没关系，它会在合适的页面预留位置，先把整套 PPT 生成出来，后面再补图。

确认需求后，Skill 会整理内容结构，从版式库中选页、填入文案并运行校验，最后生成本地预览链接。你可以在网页控制台里手动调整，也可以继续告诉 Agent：

```
把第 3 页改成时间线。  把第 6 页的柱状图换成瀑布图。  整套切换成冷白调研风。  
```

![没有现成图片时先生成占位区域](/media/ai-ppt-design/img_08.gif)

### 改完以后，还能导出可编辑的 PPTX

网页不是最终限制。

完成修改后，可以导出三种格式：

- **HTML：打包成单文件，离线双击就能打开**
- **PDF：适合打印和归档**
- **PPTX：可以交给领导、客户或同事继续修改**

PPTX 也不是把每一页截图塞进 PowerPoint。

项目的导出引擎会逐节点还原 HTML 版式，文字保持可编辑。遇到无法直接映射的复杂视觉区域，部分内容可能转成图片，但其中的文字仍会尽量从实时页面中提取出来。

所以它提供了两层编辑能力：

1. 生成后，先在浏览器中修改文字、布局、图表和配色。
2. 导出 PPTX 后，再在 PowerPoint 中继续编辑和交付。

网页负责快速调整，PPTX 负责进入真实的职场流转。先看 HTML 版和导出 PPTX 后的逐页对比：

### 安装和使用

最简单的方法，是直接把项目地址交给本地 Agent。

把下面这段话复制给 Claude Code、Codex 或其他支持 Skill 的工具：

```
帮我安装 dashiAI PPT Skill：  [https://github.com/chuspeeism/dashiAI-ppt-skill](https://github.com/chuspeeism/dashiAI-ppt-skill)     请把仓库中的 skills/dashiai-ppt/ 子目录安装到当前 Agent 的 skills 目录，  安装完成后检查 SKILL.md 是否存在，并告诉我如何调用。  
```

安装之后，可以直接发送这样的请求：

```
使用 dashiai-ppt，把这份行业研究报告制作成一套 12 页左右的汇报 PPT。     受众：公司管理层  重点：市场变化、竞争格局和下一步建议  风格：冷白调研风  要求：数据页优先使用图表，结论要突出，最后导出可编辑 PPTX。  
```

这个 Skill 不绑定某一家模型。只要 Agent 能读写本地文件、执行 Shell 命令并读取 **SKILL.md**，就可以尝试运行。

项目 README 已列出 Claude Code、Codex、豆包、Workbuddy、Marvis、Dumate、Qclaw 和 Cursor 等工具。实际效果主要取决于模型执行长任务、操作文件和遵循 Skill 的能力。

### 哪些场景适合用

它比较适合：

- 行业研究、竞品分析和趋势报告
- 年终总结、业务复盘和项目汇报
- 融资路演、产品方案和销售演示
- 内部培训、课程讲义和数据报告
- 希望文档和生成内容都留在本机的场景

使用之前，还有几点需要注意：

- 这是一套本地文件工作流，不支持多人同时在线协作
- 主题和配色使用预设方案，不适合追求逐像素自由设计的人
- 项目作者实测，一套 10 页 PPT 可能消耗约 20 万 token，文档长度和修改次数都会影响最终消耗。
- 项目主体采用 AGPL-3.0 协议。如果修改项目后用于网络服务，还需要留意对应的开源义务。
