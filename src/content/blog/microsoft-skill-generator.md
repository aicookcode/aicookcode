现在很多电脑上的重复性工作流程，都可以整理成 Skill，让 Agent 按这套流程执行就行。

但麻烦在于，很多流程用文字不好描述。人操作时觉得顺手的细节，**写成步骤时很容易漏掉**。

最近开源的**Microsoft Skill Recorder**，走的是另一条路：既然流程不好写，那就先录下来。你把重复工作完整操作一遍，它再根据录屏和上下文，**帮你生成可以复用的 Skill**。

01PART它是什么：把一次操作变成 Agent 可复用 SkillWHAT · RECORD → ANALYZE → GENERATE一句话定位：**Microsoft Skill Recorder** 是一个桌面应用，用来记录用户的一次工作会话，并通过 GitHub Copilot CLI 把操作过程**重构成可复用的 AI Agent Skill 或自动化流程**。

可以拆成三步来看：

① Record：先记录真实操作它会记录屏幕上的工作过程，**捕捉应用和窗口切换、浏览器 URL、屏幕变化、剪贴板预览**等上下文。你也可以加旁白，一边操作一边解释自己为什么这么做。

② Analyze：再分析意图和步骤点击 Analyze 后，由 GitHub Copilot CLI 分析这次记录，输出两个东西：**这次任务的总体意图，以及按顺序排列的操作步骤**。生成结果不是直接拍板，你可以先检查和修改。

③ Generate：最后生成 Skill 或 Automation

### Skill：按需调用的 SKILL.md，Agent 可以在任务描述匹配时使用它执行类似流程。

### Automation：定时或触发式流程，适合周期性任务

02PART它解决的问题：让"教 AI 做事"更接近人类示范PROBLEM · THREE PAIN POINTS① 少写一大段操作说明以前要让 Agent 执行一个流程，得先把入口、页面、字段、确认条件一条条写清楚，并且**很容易遗漏细节**。

## Skill Recorder

反过来：你先做一遍，它根据过程生成初稿。

② 把隐性的操作上下文补出来很多流程真正麻烦的不是点击，而是上下文。**人做的时候靠直觉判断**，但让 Agent 做，这些判断依据全得写出来。录屏加上旁白，能把**操作时的环境和决策过程**一起记录下来。

③ 从"一次例子"推广到"类似任务"

官方给出的例子：录一次提交表单的过程，之后可以帮助 Agent **学会提交类似的表单**。

它想做的不是让 AI 记住你的鼠标轨迹，而是**让 AI 理解这个任务大概怎么完成**。前者像宏录制，后者更像把一次示范整理成操作手册。

03PART它怎么用HOW · 安装 → 录屏 → 分析 → 生成① 先安装可以直接把这段提示词丢给你的 Agent：

...prompt帮我安装：

[https://github.com/microsoft/skill-recorder](https://github.com/microsoft/skill-recorder)

请先阅读官方 README 和安装说明，根据我当前的系统选择对应安装方式。

安装过程中不要全局安装依赖，不要改动无关文件；如果需要我授权屏幕录制、登录 GitHub Copilot，或者确认某个命令，请先停下来问我。

安装完成后，请告诉我：

1. 怎么启动 Skill Recorder；

2. 第一次使用需要授予哪些权限；

3. 如何开始第一次录制并生成 skill。

这里有个前提要注意：它需要 GitHub 账号，并且要有 Copilot 访问权限。后面的分析步骤会用到 GitHub Copilot CLI。

② 开始录屏安装完成以后，第二步就是录屏。打开 Skill Recorder，把想交给 Agent 的**重复流程完整操作一遍**。

![](/media/microsoft-skill-generator/img_01.png)

③ 分析过程做完任务后，点击 Analyze。这一步会让 Copilot 分析刚才的记录，重构出两个东西：**这次任务的总体意图，以及按顺序排列的操作步骤**。

生成结果不是直接拍板，你可以先检查和修改。这个检查环节挺重要，因为录屏只能提供过程，最终能不能变成稳定的 skill，**还得看步骤有没有被整理清楚**。

![](/media/microsoft-skill-generator/img_02.png)

④ 生成 Skill 或 Automation确认以后，就可以生成可复用结果。

如果这个流程是"我以后需要时再让 Agent 做"，那更适合生成 Skill。如果这个流程是固定时间、固定条件反复执行，那就更接近 Automation。

生成的格式目前更适配 Scout / Cowork 这类工具。如果你用的 Agent 环境不同，**拿到生成文件后可能需要做些调整**，比如修改格式、替换工具调用方式，但整体结构和步骤逻辑可以直接复用。

04PART值得注意的地方：隐私和权限要放在前面想CAUTION · PRIVACY FIRST① 录制在本地，但分析会发送数据记录发生在本地；点击 Analyze 后，数据会发送到 **GitHub 云端用于分析**。包含事件时间线、窗口或文档标题、URL、剪贴板预览、提取的屏幕图像和旁白文本。

② 不要录任何敏感信息密码、Token、API Key、凭据、客户隐私、公司内部敏感资料，都**不适合出现在录制过程里**。也不要在录制时复制、粘贴、展示或口述这些内容。

05PART适合谁AUDIENCE · WHO NEEDS THIS适合

### 经常重复做同类操作的人，比如填表、提交资料、整理网页内容

### 想给 Agent 写技能，但不想从空白文档开始写的人

### 做团队流程沉淀的人，需要把真实操作整理成 SOP 或 Agent 指令

### 对 GitHub Copilot、Agent 工作流、自动化有兴趣的开发者和技术用户

不太适合

### 只想找一个普通录屏工具的人

### 没有 Copilot 访问权限的人

### 主要流程都涉及敏感数据、无法安全录制的人

## Skill Recorder

的价值就在于：把"人演示一遍"变成"AI 能读懂的流程草稿"。但它不是魔法，**生成内容仍需要人检查、修改、确认边界**。
