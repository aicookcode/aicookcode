**终于不用一直死盯终端了,离开电脑 Claude 也会主动喊你！**ClaudeDevs 官方宣布：**Claude Code 正式支持手机推送通知！**现在，当你运行长时间任务时，完全可以放心离开电脑。Claude 会主动给你的手机推送消息，告诉你：需要你做出关键决策或提供输入、任务已完成等。

## 使用要求

- Claude Code 版本 ≥ v2.1.110（建议先运行 claude update 更新）
- 需要 claude.ai Pro / Max 订阅
- 手机安装 Claude 官方 App

## 如何开启？

1. 在手机上登录 Claude App（同一账号）
2. 在终端输入 `/remote-control` 完成配对
3. 输入 `/config`，开启 Push when Claude decides

## 这个功能有多实用？

- 跑测试、代码重构、大模型生成等长任务时，再也不用反复切回终端检查
- 减少思维中断，让开发效率更高
- 让 Claude 更像一个能独立工作的助手

很多开发者反馈：终于可以安心去喝咖啡、吃饭，回来直接看结果了。

## 写在最后

这个功能简单但极其实用，强烈建议符合条件的用户尽快升级版本并开启。
