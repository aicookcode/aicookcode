做一条三分钟的视频，配音这三分钟，比剪辑还折腾人。

念错一句，重来。背景有杂音，重来。好不容易录完，文案要修改，还得重来。

如果能让 AI 克隆自己的声音，往后只给文案，配音自动生成，就方便多了。

VoiceStudio，就是能做这件事的工具而且，它能做的还不止配音：给视频换一种语言、把文章变成有声读物、给故事里的不同角色安排不同声音，甚至直接把你说的话变成文字，都可以在里面完成。

它是一款**免费、开源的电脑软件，自带中文界面**。不注册账号、不订阅会员、没有额度限制，数据保存在你的电脑，Mac、Windows、Linux 都支持安装使用。

## 它能帮你干点啥

先看几个最容易用上的场景。

### 声音克隆

给它一小段你的录音，再输入新的文字，它就会用接近你音色的声音，把文字念出来。

### 声音设计

不想用自己的声音，可以试试“声音设计”。

你可以指定或描述性别、年龄、音高、口音、情绪这些特点，比如青年女声、中年男声，或者带点口音的讲述声。

做产品介绍、故事旁白、知识讲解的时候，多试几种声音，挑最搭内容的那一个。

### 视频翻译配音

导入一段视频，它会先识别对话内容，翻译成你要的语言，再生成新的配音，最后导出视频。

官方表示支持646 种语言，但具体能用哪些、效果好不好，得看你选的语音模型。视频翻译也有各自的语言范围。

### 多角色配音

它支持多角色配音，能分别给旁白、主角、配角安排不同的声音。生成出来的内容，就有了不同人物轮流开口的感觉，做有声书、小说多人配音最合适。

### 转录和听写

它还带听写功能，能把你说的话直接转成文字。

在桌面任意位置按住对应快捷键说话，松开后文字会输入到当前聚焦的应用中。

写长消息、记灵感、口述文章初稿，这个功能都非常实用。

## 怎么上手

### 系统要求

安装之前先看一下电脑配置。它对硬件有点要求，配置越高越顺畅；普通配置也能跑，就是速度会慢一点。

| 项目 | 最低配置 | 推荐配置 |
| --- | --- | --- |
| 操作系统 | Windows 10、macOS 12+（Apple Silicon）、Ubuntu 24.04+ | 任意现代 64 位操作系统 |
| 内存 | 8 GB | 16 GB+ |
| 显存（GPU） | 4 GB（自动将 TTS 卸载到 CPU） | 8 GB+（NVIDIA RTX 3060+） |
| 硬盘 | 10 GB 可用空间（模型 + 缓存） | 20 GB+ SSD |
| Python | 3.10+（由 uv 管理） | 3.11–3.12 |
| GPU | 可选——CPU 也能跑 | NVIDIA CUDA · Apple Silicon MPS · AMD ROCm（仅 Linux） |

### 下载

根据电脑系统，去官网下载对应安装包。

下载地址：[https://voicestudio.sh/](https://voicestudio.sh/)

### 安装

点击安装包，正常安装即可。第一次安装启动会先建一个托管 Python 环境，再下载默认模型，需要花一些时间。之后每次打开都复用，不用重下。

VoiceStudio 主要靠两类模型干活，安装时按需下载就行。
