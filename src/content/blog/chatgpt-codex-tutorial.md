AI 模型的更新速度，已经快到让人有点跟不上了。前脚刚熟悉一个版本，后脚能力更强的新模型又来了。

最近，**GPT-5.6 正式上线**，推理、编程和智能体能力再次提升，也让本来就很强的 **Codex Agent** 变得更加能打。有人已经用它写代码、做 PPT、整理资料，甚至控制浏览器完成任务。

看到这些效果，很多小白朋友也想试试，却不知道 Codex 在哪里下载、怎么安装，怎么用。再看到 CLI、Skills、MCP、AGENTS.md 这些名词，更是不知道从哪里入手。

如果你也有这些困惑，可以看看开源项目 **CodexGuide**。`这是一份从入门、进阶到实战的 Codex 中文教程。`

![alt text](/media/chatgpt-codex-tutorial/img_01.png)

截至 2026 年 7 月 14 日，项目在 GitHub 上已经获得约 **2600 个 Star**，网站整理了 **50 多篇内容和 17 个实战案例**，目前仍在持续更新。

### 从零完成第一个任务

CodexGuide 没有一上来就塞给你一堆命令，而是先解决最实际的问题：**怎么安装、怎么选择入口、怎么完成第一个任务。**在“快速上手”栏目中，你可以了解桌面 App、CLI、IDE 的区别，也可以跟着教程完成一次完整任务。

![alt text](/media/chatgpt-codex-tutorial/img_02.png)

它不只告诉你怎么开始，还会讲清楚怎样描述需求、限制修改范围、检查文件和验证结果。

![alt text](/media/chatgpt-codex-tutorial/img_03.png)

很多人使用 Codex，只会说一句“帮我改一下这个项目”，然后等着它自己发挥。任务范围太大，即使生成了很多内容，也很难判断结果是否正确。

更好的方式，是提前说清楚：

- **任务背景是什么**
- **需要完成什么**
- **哪些文件可以修改**
- **哪些内容不能动**
- **最后怎样判断完成**

`真正要学的，不只是怎么和 AI 对话，而是怎么把一项工作完整地交给它。`

### 从会用走到进阶

完成第一个任务后，就可以继续学习 AGENTS.md、Skills、Plugins、权限管理、Hooks、自动化、沙盒和 config.toml 等进阶内容。

![alt text](/media/chatgpt-codex-tutorial/img_04.png)

其中，**AGENTS.md** 可以理解成一份写给 Codex 的项目说明书。你可以提前写好项目结构、常用命令、代码规范、测试要求和安全边界，以后不用每次重复解释。

## Skills 和 MCP

则可以继续扩展 Codex 的能力，让它连接浏览器、设计工具、知识库和其他系统，把一次成功的操作沉淀成可以重复使用的流程。

项目还专门整理了权限、沙盒和审批机制。因为 Codex 不只是回答问题，它还会读写文件、运行命令和访问网络。**能力越强，越要提前划清边界。**

### 17 个真实使用案例

如果你不知道 Codex 能帮自己做什么，可以直接打开实战案例库。

![alt text](/media/chatgpt-codex-tutorial/img_05.png)

目前收录的案例覆盖了多种场景：

- **内容创作：生成 PPT、架构图、配图和动画视频**
- **知识管理：连接 Obsidian、飞书和 Notion，整理临床文献**
- **浏览器操作：使用 Playwright MCP 和 Chrome 插件执行网页任务**
- **工程开发：远程修复服务器 Bug、自动处理 GitHub Actions 报错**

这些案例的价值，不只是展示 Codex 能做什么，更重要的是告诉你：需要准备什么、怎样下达任务、如何检查结果，以及过程中有哪些风险。

项目还会区分哪些案例已经形成完整流程，哪些更偏向工具接入或场景展示，不会把所有案例都包装成完美方案。

### 为什么值得收藏

Codex 更新很快，今天的入口、配置和账号权限，过一段时间可能就会变化。CodexGuide 会在重要页面标注**最后核对日期**，并提醒读者回到 OpenAI 官方资料确认。

它也一直在强调结果验证。Codex 修改了文件、生成了内容，并不代表任务已经完成。只有检查过文件、测试、日志和最终结果，内容才真正可信。

`Codex 给出的结果不是终点，可复核的结果才是。`如果你是小白，可以先从“快速上手”开始；如果已经熟悉基础操作，可以重点学习 AGENTS.md、Skills、权限和配置；如果不知道如何用到自己的工作中，就去案例库找一个最接近的场景。

CodexGuide 不是 OpenAI 官方项目，涉及模型、价格、账号权限和功能变化时，仍要以官方文档为准。但作为一份中文学习路线，它已经把大量分散的资料和经验整理到了一起。

很多人学习 Codex，总想先找到一个厉害的提示词。真正决定它能不能进入日常工作的，却是**把任务说清楚、限制修改范围、检查执行结果，再把成功的方法保存下来。**如果你最近也想认真学习 Codex，这个项目值得收藏。
